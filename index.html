Chrome / Edge extension for people who generate scene-by-scene images on gemini.google.com. New frames go to a project folder on disk. Prompts and pictures stay in your browser.

Install Help

What it actually does

With Auto Save on, it watches only gemini.google.com. Images already in the chat are ignored. When Gemini finishes a new render, the extension writes:

Downloads/Gemini/My YouTube Story/scene_001.png

Batch Prompts is the other half: paste a script split with ===PROMPT===, keep the Gemini tab open, and it submits one scene at a time after each download. Closing the popup does not stop a run.

Details that matter on a 50-scene job

Names scene_001, scene_002… The next number is stored in this browser.
Folders One project name = one folder under Downloads/Gemini.
Duplicates A DOM re-draw of the same image is skipped. A real new render takes the next number.
Where it runs Chrome or Edge. Not on other Google sites. Not in the cloud.

Install

  1. If the Chrome Web Store listing is live, install from there. Otherwise: chrome://extensions → Developer mode → Load unpacked → select the gemini-auto-image-saver folder.
  2. Refresh any Gemini tab that was already open.
  3. Turn off “Ask where to save each file before downloading” in chrome://settings/downloads (or Edge’s downloads settings). The extension cannot click that dialog for you.
