How it works

1
You generate an image in Gemini

Keep Auto Save on. The extension watches only gemini.google.com.

2
It waits until generation is finished

Existing images in an old chat are ignored. Only newly created images are saved.

3
It writes a sequential file locally

Chrome’s Downloads folder is used. Example:

Downloads/Gemini/My YouTube Story/scene_001.png

What you get

Sequential names

scene_001, scene_002, scene_003. The counter survives refresh and browser restart.

Project folders

Each YouTube story gets its own folder under Downloads/Gemini.

Duplicate protection

Re-rendered images are skipped. A real regeneration is saved as the next number.

Fully local

No analytics, no accounts, no upload of prompts or images. Checkout is on this site; the extension never phones home.

Works in Edge

Any Chromium browser that can load Manifest V3 extensions, including Microsoft Edge.

Your settings stay here

Project name, prefix, and next number are stored only in this browser.

Install

While the Chrome Web Store listing is in review

Load the unpacked `gemini-auto-image-saver` folder in Chrome via chrome://extensions → Developer mode → Load unpacked. Refresh Gemini if that tab was already open.

If Chrome asks where to save every file, turn off “Ask where to save each file before downloading” in chrome://settings/downloads. That is a Chrome setting, not an extension setting.
