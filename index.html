How it works

  1. 1

    Open Gemini and paste a list of image prompts, split with ===PROMPT===. See the format.

  2. 2

    Start Batch. It sends one prompt, waits for a new image, then saves the file.

  3. 3

    Keep the Gemini tab open. You can close the popup. Auto Save also grabs images you make by hand.

How files are saved

Order scene_001, scene_002… The next number stays in this browser.
Folders One project name = one folder under Downloads/Gemini.
Scope Only gemini.google.com. Chrome or Edge. Nothing is uploaded.

Install

  1. Chrome Web Store if the listing is live. Otherwise chrome://extensions → Developer mode → Load unpacked → the gemini-auto-image-saver folder.
  2. Refresh Gemini if that tab was already open.
  3. In chrome://settings/downloads, turn off “Ask where to save each file before downloading.”
