Privacy Policy

Last updated: 13 September 2026

This Privacy Policy describes how the Gemini Auto Image Saver browser extension (“the Extension”) and this website handle information. Image saving and Batch prompts run on your computer. The Extension never uploads your prompts, Gemini conversations, or generated images. Checkout for Pro is a separate path on this website and uses a merchant of record (Polar or Lemon Squeezy). Anonymous Batch usage statistics are sent only if you opt in.

1. Who we are

Gemini Auto Image Saver is an independent extension. It is not created, sponsored, or endorsed by Google LLC. “Gemini” is used only to describe the website the Extension works with.

Questions: use the support link on the Chrome Web Store listing.

2. What the Extension does

The Extension runs on https://gemini.google.com/*. When you generate an image there and Auto Save is enabled, it detects the new image in the page and saves a copy to your computer using the browser Downloads system.

3. Data stored on your device

The Extension uses Chrome’s storage.local API. This data stays in your browser profile on this computer. It is not transmitted to the developer.

Stored items may include:

  • whether Auto Save is on or off
  • project name and filename prefix
  • starting number and next image number
  • notification and debug preferences
  • download delay and retry count
  • fingerprints of already processed images, to prevent duplicate downloads
  • a short local history of recent filenames and timestamps
  • Batch queue state while a prompt run is in progress
  • an optional Pro license key and its decoded payload, if you paste one
  • whether you accepted or declined anonymous usage statistics
  • an anonymous installation identifier, created only if you accept usage statistics

Generated image files are saved through the browser Downloads API, typically under Downloads/Gemini/<project name>/.

4. Data we do not collect

The Extension does not:

  • create developer accounts or require sign-in
  • send prompts, chats, or generated images to the developer
  • upload generated image files to any server
  • use advertising, tracking pixels, or third-party marketing analytics
  • sell or share user data with third parties
  • read or export Google passwords, cookies, or authentication tokens
  • collect browsing history outside gemini.google.com

You already use Gemini in your own browser session. The Extension does not add a separate connection to Google for the purpose of collecting your data.

5. Optional anonymous usage statistics

The Extension may share anonymous usage statistics only after you consent in the popup or Settings. Auto Save and Batch Prompts keep working if you decline.

If you accept, we may collect:

  • an anonymous installation identifier
  • extension version
  • whether a Batch run started, completed, stopped, or was interrupted
  • number of prompts attempted
  • success and failure counts
  • a predefined failure category, never a raw error message
  • approximate Batch duration
  • a timestamp for the event

We never collect:

  • prompt text
  • generated images
  • Gemini conversations or responses
  • filenames, folder names, or project names
  • Google account or email
  • browsing history, page text, image URLs, or download URLs
  • cookies, authentication tokens, or device fingerprints

Purpose: understand whether Batch Prompts is used and whether it completes reliably, so we can improve the Extension.

After consent, the Extension service worker sends HTTPS POST requests to our telemetry endpoint at gemini-telemetry.lusayapatrick.workers.dev. No analytics API token is stored in the Extension. You can turn this off later in Settings. Events from while it was off are not saved or uploaded later.

6. Permissions

The Extension requests only the permissions it needs:

  • storage — to remember your project settings and download counter on this device.
  • downloads — to save image files into your Downloads folder without a remote server.
  • scripting — to run the Batch prompt loop on the open Gemini tab.
  • https://gemini.google.com/* — to detect newly generated images on Gemini, request a local download, and paste the next Batch prompt. The Extension does not run on other websites.
  • https://gemini-telemetry.lusayapatrick.workers.dev/* — to send optional anonymous Batch usage events after you consent. No request is made if you decline.

7. Third parties

Daily use of the Extension does not send your prompts, chats, or images to the developer or to a license server. If you accept anonymous usage statistics, only the Batch counts listed above are sent to our telemetry service. Chrome or Edge may process downloads using the browser’s own download manager. Gemini itself is operated by Google and is governed by Google’s own terms and privacy policy.

If you buy Pro, payment is processed by a merchant of record (Polar or Lemon Squeezy, whichever is live). That provider receives the information needed to take payment and issue a receipt. After a paid order, this website’s checkout webhook receives your order id and checkout email so we can sign a license key and email it to you with Resend. We do not receive your card number. The license key is then stored only in your browser if you activate it in Settings.

The checkout provider’s privacy policy applies to payment. Resend processes the license email. We do not use that email for marketing.

8. Retention and deletion

Local settings remain until you remove them. You can:

  • change or reset settings in the Extension popup and options page, including turning off usage statistics
  • clear the Extension’s data from the browser’s extension settings
  • uninstall the Extension, which removes its stored settings from that browser profile
  • delete downloaded image files from your Downloads folder yourself

Local extension data is not stored on a remote server, so there is no cloud copy of prompts or images to delete. If you bought Pro, the checkout provider keeps the purchase record. You can delete the license from the Extension Settings on this device.

9. Children

The Extension is not directed at children and does not knowingly collect personal information from children.

10. Changes

If this policy changes, the “Last updated” date above will be revised and the new version will be posted at this URL.

11. Single purpose

The Extension’s single purpose is to save newly generated Gemini images to the user’s computer with sequential filenames. It does not inject unrelated ads, mine cryptocurrency, or alter unrelated browsing.
